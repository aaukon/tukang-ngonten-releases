# TukaNgonten — Aplikasi Video Narasi & Affiliate Otomatis (Windows PC)

**TukaNgonten** adalah aplikasi desktop Windows ringan (~6 MB) untuk kreator konten faceless (YouTube, TikTok, Reels, Shorts) dan kreator affiliate (TikTok Shop / Shopee). Susun judul, naskah, suara (TTS), puluhan gambar konsisten, subtitle animasi, musik latar, hingga render MP4 Full HD 1080p dalam satu aplikasi.

## Unduh Versi Terbaru
- **Windows 10 / 11 (64-bit):** Unduh installer TukaNgonten versi terbaru di halaman [Releases Terbaru](https://github.com/aaukon/tukang-ngonten-releases/releases/latest)**.
- *Arsip versi sebelumnya tetap tersedia di halaman Releases.*

## Fitur Utama
- **Satu Aplikasi All-in-One:** Tab terintegrasi untuk App, Gemini, Canvas, AI Studio (TTS), FlowMusic, dan Browser produk.
- **Mode Konten Umum & Affiliate:** Dukung rasio **16:9 (YouTube)** dan **9:16 (Shorts/TikTok/Reels)**, sedot info & hingga 4 foto produk Tokopedia/Shopee, kunci wajah karakter, dan fitur **Lihat Foto** (lightbox).
- **Suara AI Natural (Gratis hingga ~30x/hari per Akun Gmail):**
  - **Tab AI Studio (TTS):** ~10x generate suara gratis/hari per akun Google.
  - **Gemini API Key (Opsional di Step 1):** Tambahan **20x generate suara gratis/hari** per akun Google (10x `Gemini 3.8 Flash Lite TTS` + 10x `Gemini 3.8 Flash TTS`, otomatis berpindah saat salah satu mencapai batas harian), plus opsi *pay-as-you-go* (~Rp 185/menit) bagi pengguna volume tinggi.
- **Render MP4 Full HD 1080p Cepat:** Akselerasi GPU H.264 bawaan + cadangan mesin Hybrid FFmpeg 1080p dengan Efek Otomatis lengkap (Ken Burns, transisi, subtitle highlight kata, font custom, watermark, dan audio mix BGM/SFX).

## Cara Instalasi & Mulai Pakai
1. Jalankan `Setup-TukaNgonten-v27.exe` dan ikuti panduan instalasi hingga selesai. *(Jika muncul Windows SmartScreen, klik **More info → Run anyway**).*
2. Buka **TukaNgonten**, lalu login menggunakan **email pembelian** Anda (kode OTP 6 digit akan dikirim ke Inbox/Spam).
3. Login akun Google Anda di tab **Gemini**, **Canvas**, dan **AI Studio (TTS)**.
4. Hasil video MP4 tersimpan otomatis di folder **`Downloads\TukaNgonten`**.

## Tips Penting Jika Terkena Limit Harian Google
- Jika muncul error `403` / `429` saat generate suara (TTS) atau gambar di Canvas, itu adalah batas harian gratis dari akun Google Anda.
- Solusi cepat: klik menu **`Akun ▾`** di bar atas aplikasi → pilih akun Gmail cadangan Anda → lanjutkan produksi seperti biasa.
